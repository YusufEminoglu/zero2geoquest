about=02GeoQuest makes a quiz out of the layers you already have. Play Map Hunt directly on the QGIS canvas, compare attribute values in a duel, estimate distances, recognise polygon silhouettes and test bearings in Compass Quest, or mix them into one quest.
    Share quests as Quest Packs, keep local scoreboards, print achievement certificates, and export a game as a single HTML file that runs offline in any browser. Students play without an account and nothing is uploaded, which makes it easy to use in schools and workshops. Starter packs use UN World Urbanization Prospects data.
    Manual: https://geophilo.com/zero2geoquest/manual.html

    1.3.0 - Fair, Answerable Rounds Everywhere:
        Fixed: Ranking and Attribute Guess could only be submitted once per QGIS session; later rounds were lost on the timer.
        Fixed: Compass Quest showed no answer buttons in QGIS.
        Fixed: Distance Guess started at three quarters of the answer, which scored as correct on Easy and Medium without any input. Its range now comes from the whole quest, in metres for city-scale data.
        Fixed: The Value Hint joker could exclude the answer; its window now always contains it. Eliminate is no longer spent on two-way duels.
        Fixed: Play again after a Quest Pack switched to the selected layer; replay and HTML export now keep the pack.
        Fixed: Value Duel compared a numeric field with polygon area when only some features had values.
        Fixed: Blind Zoom and Map Hint on point layers zoomed to an empty extent.
        Fixed: Map Hunt ignored the target when another polygon overlapped it, and scanned the whole layer per click.
        Fixed: Starter pack populations mixed city-proper and metropolitan figures; all three packs now use UN World Urbanization Prospects 2018.
        Fixed: Silhouettes from geographic layers were stretched east-west; offline silhouettes were stretched to fill the frame.
        Fixed: The offline HTML game asked the same questions on every load and in every replay.
        Added: Offline HTML uses the quest difficulty, lives and scoring formula, keyboard play, best streak and a personal best.
        Added: Keys 1-9 and Enter in the dock, a Pick on map button, prompts naming the chosen field, evenly sampled large layers.
    1.2.3 - Redesign plugin icon to high-end 3D tactile brand design with circular teal pedestal, zero margin, and refreshed documentation links.

        Fixed: Removed a literal percent character from plugin metadata so QGIS Hub can parse and validate the release package.
    1.2.0 - Reliable Quest Packs & Balanced Play:
        Fixed: Imported and built-in Quest Packs now launch from their own records instead of being overwritten by the selected QGIS layer.
        Added: Shuffle-bag mode rotation presents every selected mode before repeating one and avoids consecutive repeats.
        Added: Strict portable-pack validation for modes, difficulty, WGS84 coordinates, finite values, duplicate ids, playability, file size and record count.
        Added: Atomic Quest Pack saves and collision-free portable ids for mixed-layer exports.
        Fixed: Score closeness multipliers are bounded to prevent malformed inputs from inflating scores.
        Improved: Challenge fallback tries each selected mode exactly once and reports a useful failure reason.
    1.1.1 - Ranking Mode Usability & Reordering Controls:
        Added: Move Up (⬆️) and Move Down (⬇️) buttons for reliable, accessible ranking reordering alongside drag-and-drop.
        Added: Dynamic rank badge indicators (🥇 1st Highest, 🥈 2nd, 🥉 3rd, 🔻 4th Lowest) updating live as items are sorted.
        Fixed: Enhanced submit ranking handler with clean UserRole data mapping, preventing text truncation or missing items.

    0.9.0 - Complete alpha: four game modes, quest builder, canvas interaction, scoring, leaderboard, bilingual UI and standalone offline HTML export.
